# 普通话转法语口播神器

独立 Codex Skill：将普通话口播视频制作成法语配音版，核对原意与情绪，完成音画和口型同步，并按需交付可导入剪映的 SRT。

## 工作内容
- 校对法语译文，保留原文事实、数字、地点、顺序和语气；有歧义先确认。
- 优先本地 TTS；使用云端前核实当前价格、免费额度、时长限制和水印。
- 按最终法语音轨同步口型，不误删仍在说话的画面。
- 核验 MP4，并制作与法语音轨匹配的 UTF-8 SRT。
- 自动识别不支持法语时，直接导入 SRT 到剪映/CapCut。

## 安装与调用
将整个 mandarin-to-french-lipsync 目录放入 Codex Skills 目录，例如：

    ~/.codex/skills/mandarin-to-french-lipsync/

保持 SKILL.md 在目录根部，重新加载 Skills 后显式调用：

    $mandarin-to-french-lipsync

## 使用边界
- 云端上传人脸或声音素材前，说明文件、目的地和用途并取得本次授权。
- 不自动购买、升级或重试收费任务；每次核实实时额度与价格。
- 保留源文件；只裁掉确认的无对白片段。
- 不替换人脸/数字人形象，不负责公开发布。
- Skill 不含视频、声音样本、转写稿、私人路径或账户信息。
