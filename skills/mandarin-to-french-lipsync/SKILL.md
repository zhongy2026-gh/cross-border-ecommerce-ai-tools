# 普通话口播转法语与口型同步

把普通话口播视频制作成法语配音版本，并交付已验证的本地 MP4 与可选 SRT。沿用用户本次明确的语气、声线和工具偏好；Skill 调用不代表授权上传媒体、消耗额度、购买方案或重试付费任务。

## 成功标准
- 法语保留原文事实、数字、地点、顺序和口语语气；有歧义时先确认译文。
- 按用户本次指定的情绪和声线优先级生成配音。若未指定，先询问；不要把个人偏好硬编码成通用默认值。
- 输出画面与法语音轨同步；不误删有效对白；下载到本地并核验音视频轨、时长和分辨率。
- 用户需要字幕时交付 UTF-8 SRT，按实际法语音轨计时。

## 输入与选择
复用本次已给材料，只询问会改变结果的缺项：源视频或清晰人声轨、普通话稿（没有稿时先转写并校对）、法语口音/风格、配音参考音频及准确文本、字幕和画幅要求。确认参考声音有权使用；不把音频放进 Skill 或公开仓库。

优先本地 TTS。模型、硬件和路径视为本机配置，不假定其他设备也可用。改用云端 TTS 前，说明服务商和费用并取得该次授权。口型同步优先用用户指定的服务；每次重新核实免费额度、时长限制、水印和价格。剪辑软件不能识别法语时准备可导入 SRT，不额外烧录字幕。

## 工作流程
1. **检查素材。** 用 ffprobe 读取时长、画幅、帧率和音轨；观察人物说话起止与镜头变化。保留原件。
2. **定稿法语。** 核对数字、地点、时态、因果和语气。展示法语原句及必要中文释义，确认后再生成；不为迁就时长擅自改意。
3. **生成配音。** 先做低成本样片。参考音频克隆时准确提供参考稿。检查时长、头尾静音、削波与可懂度。
4. **解决时长差。** 只裁掉已确认的无对白片段。若音轨短于人物仍在说话的画面，不截掉对白或大幅变速；说明裁切、静音延长、时间重映射的影响，再按用户意图选择。提交同步前核对模型、时长和费用。
5. **提交一版口型样片。** 上传人脸或声音媒体前，确认具体服务商、文件和用途获本次授权。优先账户确认免费的模型；收费、升级或额度不明时先停下说明。失败后不自动重试或换付费模型。
6. **审核与下载。** 抽查开头、中段、结尾口型、情绪、音画时序和尾部动作。认可后下载已完成结果；下载失败先检查下载目录，不重新生成。等待 .crdownload 下载完成，再用 ffprobe 核验轨道、时长、分辨率并注明水印。
7. **制作字幕。** 以最终法语音轨和定稿制作 SRT。优先强制对齐/词级时间戳；否则按停顿做短句级时间轴并说明精度。检查编号、时间递增、无重叠、结束时间不超片长、拼写一致。用户自行处理样式时只交付 SRT。
8. **交付。** 提供本地 MP4/SRT 路径、参数、水印、实际费用或额度消耗及用户后续事项。文件存在且验证通过后才称为成片已交付。

## 成本与隐私
- 实时核对价格、免费额度和会员权益；本地剪辑会员不等于云端生成额度。
- 未授权的云端上传，先说明服务商、具体视频/音频和用途并等待同意；授权仅适用于该素材和任务。
- 付费生成、升级、更高质量模型或收费重试前，给出准确费用并取得确认。
- 不将示例媒体、参考声音、转写稿、用户姓名、账户标识、私人路径、密钥或个人项目 URL 放进公开 Skill。
- TapNow 不是此流程必需工具；仅在用户另行要求视觉素材时使用。
