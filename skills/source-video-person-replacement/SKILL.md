# 源视频人物替换与口型同步

默认流程：无字幕源视频 → 本地短片准备 → Hypit 人物替换 → 画面验收 → Sync 口型同步 → 本地验收 → 按需添加字幕。

## 输入与能力边界

复用用户已提供的源视频、目标形象图、最终音轨和已确认参数，只问会影响制作的缺项。默认保留源视频声音，不翻译、不克隆声音、不重新配音。用户指定配音时，以已批准的最终音轨为口型依据。

优先无内嵌字幕的源片。若已有内嵌字幕，说明生成可能改写文字，优先索取无字幕版本；用户明确接受样片验证时可继续，不自动去字幕、裁画面或添加字幕。字幕在人物和口型验收后，按最终音轨制作；默认先交无新增字幕版。

形象图优先清晰、无遮挡单人图，表情和角度接近源片；多视图素材应明确各视图属于同一人物。图片定义外观，视频提供动作与镜头参考，音频用于最终嘴形。

Hypit 路线属于生成式重演，可能改变景别、背景、手势、道具、表情和字幕；不能承诺只换身份而其他元素严格不变。Sync 可以重做嘴形，不会恢复这些变化。若用户要求严格保持所有其他元素，先说明此路线不满足，不直接提交。

## 节省额度执行

- 先读取本项目交接和当前任务状态，复用已安装环境、授权和批准模板；不重新扫描历史、安装或升级工具。
- 本地完成探测、裁剪、音轨提取、封装、抽帧和对照。用已有 CLI/脚本完成机械操作，日志留本地，仅回传任务ID、状态、错误摘要和结果路径。
- 默认先做有代表性的 5 秒、480P、一次样片，选清晰说话并含适量动作的连续片段；用户明确参数优先。短样片通过不等于全片已获批。
- 保存阶段记录：输入、起止时间、模型与参数、报价及授权、Build/任务ID、输出、验收和下一步。中断后续接原任务，不重新提交。
- 不为等待进度反复让模型推理；使用工具原生跟随或本地等待。无法回调的网页可适度查询同一任务。

## 制作步骤

1. **本地准备。** 用 ffprobe 核对视频、音轨、时长，抽帧确认人物和遮挡。新任务建独立目录，保留原件。视频与音轨截取同一时间段；不大幅变速、不任意错移音频。准备可播放参考片和独立音轨。
2. **人物替换。** 优先复用已验证的 Hypit Seedance 2 Mini 参考视频模板；提交前核对当次模型支持及实时报价。图片参考定义身份，视频参考定义表演，关闭生成音频。要求尽量保留镜头、场景、动作、情绪及手持物，不把这些提示词当作效果保证。
3. **提交一次。** 明确上传素材、目的地与费用；本次已有明确授权就直接继续，不重复询问。没有本次费用授权时给出报价后等待确认。提交后立即记录ID；提交结果不明先查已有任务，不自动补交。失败先查状态与结算，不自动收费重试。
4. **画面验收。** 下载替换结果，本地回贴原声仅供预览，明确回贴不等于口型同步。检查身份、表情、手部、道具、构图和文字。画面不通过时先解决，不继续消耗口型额度。用户已认可画面并授权修口型时直接进入下一步。
5. **口型同步。** 将替换视频与对应最终音轨提交 Sync。每次从账户页面核对免费次数、具体模型资格、长度限制、水印和费用。免费总次数不代表 sync-3 等每个模型都有免费资格；已有免费授权可选择可用免费模型。此前 lipsync-2-pro 的短片效果获用户认可，但不是未来免费或成功保证。收费、升级或免费资格不明时停在具体报价处。不重复生成以解决下载问题。
6. **本地交付。** 下载同一条同步结果，保留免费水印。核对音视频轨、时长、尺寸并完整解码，抽看开头、中段、结尾的脸部和嘴形。可制作左修复前、右修复后的对照，避免双音轨叠放。向用户提供本地文件，说明费用/免费次数及水印，等待实际口型与观感验收；不能以接口成功或解码通过代替用户验收。
7. **后续制作。** 样片通过后再确定全片长度、分段及报价。字幕以最终音轨为准，按需交 SRT；未经要求不烧录字幕，不上传发布。

## Hypit 续接要点

在现有运行配置所在目录使用已安装的 Hypit。先运行 check、plan、pricing；build 会创建任务，只在当次授权后执行一次。status 或 status --watch 用于续接，logs --lines 20 用于有限诊断，get 用于导出既有结果。以本机 CLI 帮助核对参数，不重新安装整套工具。

若沙箱报告凭据缺失，而相同运行配置此前已授权，先判断系统凭据访问限制，按环境权限流程处理，不重复 OAuth 或复制密钥。所有状态记录和 Skill 均不包含密钥。

## 输出记录

每个任务至少保留：原片与目标图路径、取段时间、最终音轨路径、生成参数、当次费用依据和授权、Hypit Build ID、Sync项目/任务入口、下载结果、技术检查、用户验收结论。Skill 包本身不包含用户媒体、私人路径、账号或具体任务链接。
